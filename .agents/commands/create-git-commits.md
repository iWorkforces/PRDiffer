# Create Conventional Commit-style git commit(s)

Your task is to quickly create informative git commit(s) for all new code changes. Each commit is atomic, focused on a single logical change, and small enough to review easily.

Use the Conventional Commits format for every commit message:

```text
<type>(<optional scope>): <imperative description>
```

Choose the semantic type that best describes the change, such as `feat`, `fix`, `docs`, `refactor`, `test`, `perf`, `build`, `ci`, `chore`, or `style`.
